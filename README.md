# Solveo

Solveo — помощник для разбора задач и вопросов по тексту и скриншотам на Windows. Подготовьте контекст собеседования или рабочей задачи, снимите нужную область экрана и получите ответ с объяснением и кодом. Продолжайте разговор в том же чате — текстом или новыми снимками.

## Возможности

- **Подготовка чата.** Заранее опишите, что будет происходить, какие задания вы будете присылать и как нужно отвечать. Преднастройка сохраняется без обращения к модели.
- **Вопросы со снимками и без них.** Отправьте обычный вопрос, снимок области или несколько изображений в одном запросе. В очереди помещается до 20 снимков.
- **Ответы под вашу задачу.** Выберите язык ответа, язык кода, подробность, модель и доступный ей уровень рассуждения. Код и ответы можно копировать.
- **История разговоров.** Возвращайтесь к чатам, просматривайте отправленные снимки и продолжайте обсуждение.
- **Удобное рабочее окно.** Закрепляйте его поверх других окон, скрывайте в трей, меняйте тему, масштаб интерфейса и размер текста.

Сейчас ответы доступны через Codex. Список моделей и уровней рассуждения загружается из этого подключения; запоминать названия вручную не нужно.

## Как запустить

Для работы нужны Windows x64, WebView2 Runtime и установленный Codex CLI, доступный в `PATH`.

1. Авторизуйтесь в Codex командой `codex login`.
2. Запустите `Solveo.exe` из папки, в которой разрешена запись: рядом приложение будет сохранять чаты, снимки и настройки. Если запускаете из исходников, сначала выполните сборку ниже — EXE появится в `build/bin/`.
3. Откройте настройки Solveo и нажмите «Проверить соединение». Проверка отправит отдельный короткий запрос модели.
4. Нажмите «Преднастройка», чтобы подготовить контекст, или сразу введите вопрос. Для снимка используйте кнопку в окне или горячую клавишу.

Enter отправляет вопрос, Shift+Enter добавляет строку. Крестик скрывает окно; открыть его снова можно из трея или через Ctrl+Alt+O. Для завершения выберите выход в трее или настройках.

### Горячие клавиши

| Действие | Клавиши |
| --- | --- |
| Выбрать область и сразу получить ответ | Ctrl+Alt+S |
| Добавить область в очередь | Ctrl+Alt+A |
| Снять основной экран и получить ответ | Ctrl+Alt+F |
| Отправить текущий вопрос и очередь снимков | Ctrl+Alt+Enter |
| Показать или скрыть окно | Ctrl+Alt+O |

Быстрый снимок отправляет только новый кадр: набранный вопрос и накопленная очередь остаются для отдельной отправки. Esc отменяет выбор области.

## Сборка из исходников

Пока готовых релизов нет, приложение можно собрать самостоятельно. Нужны Go 1.25+, Node 24+, Vite+ CLI (`vp`), pnpm и Make. Установка Vite+ описана в [официальном руководстве](https://viteplus.dev/guide/).

Из корня репозитория:

```sh
cd frontend
vp install --frozen-lockfile
cd ..
make build
```

Запустите полученный `build/bin/Solveo.exe` на Windows. Для готового приложения инструменты сборки не требуются. Собирать Windows-версию можно также из WSL.

Для запуска в режиме разработки на Windows используйте `make dev`, для проверки проекта — `make check`.

Если Codex отсутствует в `PATH`, укажите путь при запуске:

```powershell
.\Solveo.exe -codex "C:\path\to\codex.exe"
```

## Настройки и данные

Чаты, сохранённые снимки и настройки находятся в `solveo-data` рядом с `Solveo.exe`. Тема, масштаб интерфейса 80–150%, размер текста и закрепление сохраняются автоматически в `solveo-data/settings.json`. Для переноса или резервной копии сохраните папку `solveo-data` целиком. Для продолжения прежнего диалога также нужна его сессия Codex в текущем профиле пользователя.

Неотправленные вопросы и очередь снимков сохраняются только до выхода из приложения. Отправленные вопросы и изображения передаются Codex для получения ответа.

Если запрос завершился ошибкой, очередь остаётся для повторной отправки. После отмены или обрыва автоматического повтора нет. Если не удалось сохранить полученный ответ, он остаётся в окне: в настройках можно повторить сохранение или выбрать «Новый без сохранения». Эта команда отбрасывает несохранённый ответ и переносит очередь снимков в новый чат.
