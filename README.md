# Solveo

Помощник для вопросов и заданий на Windows: подготовка контекста чата, текстовые вопросы, снимки экрана и ответы с Markdown и кодом. Go + Wails, React/TypeScript через Vite+ и pnpm.

Преднастройка сохраняется локально и не обращается к модели. Вопрос можно отправить без снимка, а снимки — продолжать в том же диалоге. Сейчас работает только Codex CLI; другие подключения и голосовой ввод предусмотрены в проекте, но пока не реализованы.

## Запуск

Windows x64, установленный WebView2 Runtime и авторизованный Codex CLI в `PATH`. Сборка находится в `build/bin/Solveo.exe`. Node, pnpm и Vite+ для готового EXE не нужны.

Крестик скрывает окно. Открыть его снова можно из трея или через Ctrl+Alt+O. Завершение — через трей или настройки Solveo. Закрепление поверх окон доступно в заголовке и трее, сохраняется между запусками.

| Действие | Клавиши |
| --- | --- |
| Выбрать область и сразу получить ответ | Ctrl+Alt+S |
| Добавить область в очередь | Ctrl+Alt+A |
| Снимок основного экрана и ответ | Ctrl+Alt+F |
| Отправить текущий текст и очередь | Ctrl+Alt+Enter |
| Показать или скрыть окно | Ctrl+Alt+O |

Быстрый снимок отправляет только новый кадр. Текст и накопленная очередь остаются для отдельной отправки. Максимум очереди — 20 снимков. Esc отменяет выбор области. Enter отправляет вопрос, Shift+Enter добавляет строку.

## Разработка и сборка

Нужны Go 1.25+, Node 24+, Vite+ CLI (`vp`) и pnpm. Версии frontend-зависимостей закреплены в `frontend/pnpm-lock.yaml`; менеджер пакетов — pnpm 12.14.0. Установка Vite+ — по [официальной инструкции](https://viteplus.dev/guide/).

```sh
cd frontend
vp install --frozen-lockfile
cd ..
make check
```

`make build` создаёт `build/bin/Solveo.exe`, включая frontend. На WSL можно собрать и проверить Go-логику, TypeScript и Windows vet. `make dev` запускает Wails и Vite+ на Windows. По умолчанию `make` показывает команды.

Основные параметры запуска: `-codex <path>`, `-timeout 10m`, `-prompt-file <UTF-8 file>`. Старый `-keep` принимается для совместимости: отправленные изображения и сообщения теперь архивируются.

Frontend использует строгий TypeScript, проверки небезопасных операций и Zod на границе с Go. Код Wails генерируется через `make bindings`; вручную его не редактируют.

В преднастройке языки выбираются из списков. Модели и доступные каждой модели уровни рассуждения загружаются через `codex app-server` (`model/list`); нужен Codex CLI с поддержкой этого метода. Каталог можно обновить кнопкой. При ошибке загрузки сохранённые параметры не затираются. Сам Codex может вернуть свой кеш или встроенный каталог при недоступности сервиса; получение списка не отправляет вопрос модели.

В общих настройках доступен масштаб основного интерфейса 80–150%, отдельно от размера текста. Масштаб, тема, размер текста и закрепление сохраняются автоматически в `solveo-data/settings.json` и восстанавливаются при запуске.

## Данные и приватность

Чаты, настройки и PNG хранятся в `solveo-data` рядом с EXE; профиль WebView2 — в `%LOCALAPPDATA%\Solveo\WebView2`. Для переноса истории скопируйте `solveo-data`. Старые JSON и соответствующую папку `images` Screen Codex можно скопировать в `chats` и `images` этого архива: чтение schema v1 поддерживается, исходные файлы при открытии не переписываются. Для продолжения старого чата нужна его CLI-сессия Codex в текущем профиле пользователя.

Отправленные вопросы и снимки передаются выбранному подключению, сейчас — Codex. Неотправленная очередь и черновики находятся в памяти/временных файлах до выхода. При ошибке запроса они сохраняются для явного повтора. После отмены или обрыва приложение не повторяет запрос автоматически: внешний сервис уже мог его принять.

При ошибке записи ответ остаётся в окне. В настройках доступны повтор сохранения и «Новый без сохранения»; последняя команда отбрасывает несохранённый ответ и переносит очередь в новый чат.

Сборка и автоматические тесты не проверяют поведение Win32/WebView2 в записи экрана. Реальные проверки на Windows перечислены в [чек-листе](docs/windows-acceptance.md). Гарантия невидимости во всех программах захвата не заявляется.
