# Проверка Solveo на Windows x64

Статус: Windows runtime в WSL не выполнялся. Автоматические проверки и браузерный макет не заменяют этот список. Используйте отдельную папку с тестовым `solveo-data`; реальные вопросы и PNG отправляйте только после проверки подключения.

## Окно и запуск

- [ ] Запустить `build/bin/Solveo.exe`: нет консоли, видны трей и главное окно после загрузки UI.
- [ ] Повторный запуск с тем же архивом отклоняется; после завершения/аварийного закрытия запуск снова доступен.
- [ ] Ошибки установки affinity/трея не показывают незащищённое окно; стартовая ошибка видима через диалог.
- [ ] Крестик скрывает окно, Ctrl+Alt+O и трей открывают; выход есть также в настройках.
- [ ] Перезапуск Explorer восстанавливает трей. При отказе восстановления главное окно открывается, в настройках доступен выход.
- [ ] Смена темы, 100/150/200% DPI и размер 520×400: текст вводится целиком, кнопки и composer доступны, длинный код прокручивается внутри блока.

## Настройки моделей и читаемость

- [ ] В общих настройках сменить масштаб интерфейса на 80/125/150%: увеличиваются кнопки, панели и текст; настройка остаётся доступной при 520×400.
- [ ] Перезапустить приложение: масштаб, тема, размер текста и закрепление восстановлены из solveo-data/settings.json; архив чатов и PNG остаётся доступным.

- [ ] Языки ответа и кода выбираются из списков; прежние пользовательские значения сохраняются.
- [ ] При открытии преднастройки загружаются модели Codex; для разных моделей доступны только их уровни рассуждения. Смена модели сбрасывает прежний уровень.
- [ ] Обновление каталога и ошибка подключения не стирают введённый контекст или сохранённые параметры; загрузка списка не создаёт чат/ответ.
- [ ] Старые настройки с текстом 15 px показывают 17 px; после сохранения и повторного запуска размер не увеличивается снова. Кнопки, подписи и поля стали крупнее.
- [ ] В просмотрщике и журнале видны фон, подписи и кнопки в обеих темах; переключение темы при открытом окне перерисовывает их.

## Чат

- [ ] Создать преднастройку без запроса; перезапустить, открыть её из истории и проверить поля.
- [ ] Отправить первый текст без снимка. После успешного ответа отправленный текст очищен.
- [ ] Нажать Enter сразу после ввода; текст не остаётся для случайного повтора.
- [ ] Набрать следующий вопрос во время запроса: новый черновик остаётся после ответа.
- [ ] Shift+Enter добавляет строку. Enter при IME composition не отправляет запрос.
- [ ] Сменить контекст/модель и проверить следующий запрос; история содержит предыдущие сообщения.
- [ ] Новый чат получает собственную настройку и черновик; возврат сохраняет неотправленный текст.
- [ ] Копирование ответа и кода работает; Markdown не загружает внешние картинки и не выполняет HTML.
- [ ] Проверка соединения использует выбранные модель/усилие и не меняет чат/очередь.

## Снимки и окна

- [ ] Ctrl+Alt+A выбирает область; Esc/правый щелчок отменяют её без файла/запроса.
- [ ] Очередь отправляется в порядке добавления. Удаление одного и очистка очереди работают.
- [ ] Быстрый Ctrl+Alt+S/F отправляет только новый снимок, не текст и не прежнюю очередь.
- [ ] При 19 снимках и ошибке быстрого запроса остаётся 20; при 20 selector не запускается.
- [ ] Просмотрщик: вписать/1:1/масштаб/перетаскивание/предыдущий/следующий/Esc. Закрытие не завершает Solveo.
- [ ] После отправки очереди открытый просмотрщик продолжает работать с архивными копиями.
- [ ] Журнал доступен при скрытом главном окне; отмена завершает дерево Codex, включая `.cmd` launcher.
- [ ] Главный экран, selector, просмотрщик и журнал проверить в используемых программах захвата/Zoom.

## Закрепление

- [ ] Включить «поверх окон» в заголовке/трее. Скрыть, получить ответ: окно остаётся скрытым.
- [ ] Повторно открыть: закрепление включено. Selector и просмотрщик не перекрываются главным окном.
- [ ] Перезапустить приложение: закрепление сохранено. Перезагрузка renderer не показывает скрытое окно.

## Ошибки и архив

- [ ] Повредить отдельный тестовый JSON: здоровые чаты доступны. Старый schema v1 открывается со снимками.
- [ ] Отмена/таймаут/потеря связи отмечены отдельно, нет автоматического повтора и нет второго user turn при явном retry.
- [ ] Симулировать отказ записи до запуска CLI: запрос не запускается, PNG сохранён для выбора.
- [ ] Симулировать отказ записи после ответа: ответ виден, отправка/смена/выход заблокированы до recovery.
- [ ] Восстановить запись, повторить сохранение: ровно один ответ в архиве.
- [ ] При постоянной ошибке «Новый без сохранения» создаёт новый чат и сохраняет очередь снимков; повтор модели не запускается.
- [ ] Принудительно закрыть во время запроса: после запуска попытка отмечена как прерванная, автоматической отправки нет.
