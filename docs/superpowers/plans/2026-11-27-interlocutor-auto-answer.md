# Автоответы на вопросы собеседника

Режим включается явно в настройках аудиоокна. Системные реплики проходят через
существующий сборщик. Готовая автоматическая карточка отправляется через обычный
контроллер чата. Ручные карточки требуют отдельного действия.

- Расширить результат сборщика признаком исправления последнего вопроса.
  Самостоятельные вопросы, включая вопросы по той же теме, остаются отдельными.
- Сохранять ID последнего автоматически отправленного вопроса до выключения
  режима или следующей отправки. При исправлении проверить этот ID и объединить
  исходные реплики. Если прежняя генерация ещё идёт, закрыть её поток, отменить
  вызов и дождаться результата отмены. Запустить новую попытку на том же
  сообщении с учётом уточнения. При неизвестном исходе остановить автоответы.
- Добавить управление в аудиоокне и выключать автоответы при остановке
  прослушивания и переходе между чатами. Сохранять режим только в памяти.
- Проверить через поддельный провайдер исправление во время генерации и после
  завершения, независимый вопрос, отмену и архив. На Windows проверить живое
  распознавание, задержку и семантическую классификацию.
