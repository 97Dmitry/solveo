# Отдельное окно автоответов

- Выделить сессию автоответов со своим архивом, тредом Codex и состоянием
  генерации. Переиспользовать контроллер отправки и правила безопасной замены
  ответа. Передавать туда системную транскрипцию независимо от навигации чата.
  Проверить параллельный ручной запрос, уточнение и открытие сохранённой сессии.
- Переиспользовать запуск отдельного Windows-окна и локальный IPC с отдельным
  токеном. Список содержит заголовки и статусы, а текст запрашивается только
  для раскрытого вопроса. Пауза, смена сессии и вставка идут через родителя.
- Сделать компактный аккордеон с устойчивым открытием и прокруткой, потоковым
  Markdown, переходом к новому вопросу и копированием. Добавить вход из
  аудиоокна. Закрытие окна скрывает его, сохраняя состояние сессии.
- Проверить обработку уточнения и нового вопроса из одного анализа, UI с
  потоком и обновлением списка, IPC, Go race suite и сборку Windows x64.
