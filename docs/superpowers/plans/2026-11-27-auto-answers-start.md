# Запуск автоответов из одного окна

- По одной команде проверить конфигурацию, запустить выбранный распознаватель
  и открыть системный звук. Если микрофон уже работает, повтор открытия
  системного звука не должен его прерывать. Пауза отменяет отложенное
  включение автоответов.
- Показывать состояние готовности по системному источнику, а также запуск,
  паузу, анализ и объяснение сбоя. Убрать дублирующий переключатель
  автоответов из настроек ручного сборщика.
- Передавать автоматическому сборщику новые реплики и источники актуального
  черновика. При исправимой ошибке ссылок выполнить одну проверку на том
  же снимке. Ответы и накопленные условия меняются только после валидного
  результата.
- Проверить запуск из остановленного состояния, отказ системного входа
  при работающем микрофоне, паузу, ошибку ссылок и полный Windows-билд.
