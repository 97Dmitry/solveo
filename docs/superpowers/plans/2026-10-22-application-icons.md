# Иконки Solveo

Выбран пользователем вариант 1: геометрическая фиолетовая S. Задача — заменить
шаблонную Wails W и дать трею узнаваемый знак, читаемый при малом размере.

## Решение и ограничения

- Приложение: S на тёмной скруглённой плитке, прозрачность снаружи.
- Трей: отдельная прозрачная фиолетовая S. Цвет сохраняет видимость на светлой
  и тёмной панели Windows без привязки к теме интерфейса Solveo.
- `build/appicon.png` и `build/windows/icon.ico` обновляются вместе: Wails
  сохраняет существующий ICO, а не генерирует его заново из изменённого PNG.
- PNG трея встроен через `go:embed`; `CreateIconFromResourceEx` создаёт HICON
  размером `SM_CXSMICON` / `SM_CYSMICON`. Без файлов рядом с EXE и временных файлов.
- HICON принадлежит native host: удалять из Shell перед `DestroyIcon` как при
  отказе запуска, так и при выходе; сохранять при восстановлении Explorer.
- Переезд между мониторами и изменение DPI уже работающего трея отдельно не
  обрабатываются. Масштабирование Shell требует проверки на Windows.

## Происхождение графики

Графика подготовлена встроенным `imagegen`, затем приведена к размеру через
ImageMagick. Итоговые ресурсы находятся в репозитории, от внешнего генератора
при сборке не зависят.

Промпты: извлечь из выбранного эскиза только геометрическую фиолетовую S,
сохранив силуэт и пропорции, на прозрачном фоне; отдельно извлечь верхнюю иконку
с тёмной скруглённой плиткой, убрав номер, фон презентации и нижний значок.
Ограничения: без текста, новых деталей, теней и свечения.

Обновление ICO из PNG:

```sh
magick build/appicon.png -define icon:auto-resize=256,128,64,48,40,32,24,20,16 build/windows/icon.ico
```

Win32 принимает PNG непосредственно как ресурс иконки:
[Microsoft: The format of icon resources, revisited](https://devblogs.microsoft.com/oldnewthing/20231025-00/?p=108925).
