# Безопасный пересмотр автоответов

- Определять целевую карточку по ID из ограниченного контекста сессии.
  Отбрасывать чистый шум и проверять, что автоматический результат опирается
  на новую системную реплику. Сохранять источник предыдущего черновика только
  для его продолжения.
- Сохранять попытку пересмотра отдельно от успешного вопроса и ответа.
  Обновлять выбранную пару только после успешного результата, включая
  карточку, после которой появились другие вопросы. Восстанавливать
  прерванную попытку с явным повтором.
- Показывать пересмотр, ошибку и повтор в соответствующей карточке.
  Проверить правильно классифицированный шум, ошибочную классификацию,
  пересмотр прежней карточки, сбой, восстановление и новый вопрос.
