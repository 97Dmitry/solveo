# Speech recognition worker

- Python package `solveo_stt` runs inside the `solveo-stt` image built from this directory; `embed.go` ships the build context inside Solveo.exe. Tests and anything outside the embedded file list never reach the image.
- `engine.Track` owns utterance boundaries: Silero VAD on 512-sample windows, 300 ms pre-roll, 1 s of new audio per streaming step, 20 s forced final. The final is always one offline `transcribe()` over the whole utterance (hybrid final); `finish_streaming_transcribe` is never called. A step that hits the 32-token cap stalls partials for that utterance, never the final.
- `qwen.py` is bound to qwen-asr 0.0.6: `step` moves backlog into `state.audio_accum`/`state.buffer` so one decode covers it. Re-read upstream `qwen_asr/inference/qwen3_asr.py` before changing the pin. Token caps swap `sampling_params` clones; never mutate the shared object.
- vLLM settings, model revision and the context template are fixed by the stage plan («Решения 9.0»); change them only with a new measurement in `docs/roadmap/2026-10-22-local-stt-evaluation.md`.
- Serving never downloads (`HF_HUB_OFFLINE=1`); only the `download` subcommand touches the network. Check model registration with `qwen.check_registered()` before loading.
- Protocol v1 (`server.py`): `/health` and `/v1` require `Authorization: Bearer $SOLVEO_STT_TOKEN`; both answer 503 until the model is warmed up. Binary frames are `uint32 LE header length + JSON {stream_id, seq, rate, channels} + float32 LE interleaved`, ≤ 64 KiB, seq without gaps; audio is downmixed and resampled (soxr HQ) here. One model thread serves all streams round-robin with finals first (`pick_next`); a failed decode or a protocol error ends only that stream. The process exits 30 s after its last session (lease) or when loading fails.
- `requirements.lock` is a freeze delta over the pinned base: regenerate with `LOCK_DELTA_PRE='blinker==1.9.0' tools/audio-bench/docker/lock-delta.sh 'qwen-asr==0.0.6' 'silero-vad==6.2.3' 'websockets==17.2'`, drop fastapi/starlette, never hand-edit versions.
- Tests: `make stt-worker-test` (uv, Python 3.12, numpy pinned to the base image). Fakes mirror qwen-asr semantics; no torch, GPU or model in unit tests.

- Only the hybrid final context enriches selected dictionary terms found in `solveo_stt/pronunciations.json` (case-insensitive lookup, preserves user spelling/order). These are model hints, never transcript replacements. Canonical entries take priority: optional hints are omitted when they would exceed the 4096-byte context budget. Empty dictionary remains empty. The JSON is embedded into the build context and changes the image tag. Measured choice: 2026-10-23 quality section of the STT evaluation report. The tokenizer overlay experiment was rejected; do not enable fix_mistral_regex in vLLM without new evidence.
- `Track.partial_context` is the canonical-only dictionary, `Track.context` is the enriched final dictionary. Never feed pronunciation hints into streaming state: replay measured a preview regression (48→46/63 terms) with hints in both phases. The server builds both strings at Open; final uses one unchanged-audio offline pass.
