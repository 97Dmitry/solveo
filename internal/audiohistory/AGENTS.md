# Audio text archive

- Independent version-2 ASR parts (version 1 remains readable), text only: no PCM, credentials or provider state. DTOs and validation here are the archive contract; controller must validate final rows before scheduling persistence.
- Files are `<32 lowercase hex>.json` directly under the configured directory. All archive file operations use `os.Root`; only Save creates storage. Errors must not expose raw documents, paths or credentials. Save preserves unsupported, corrupt or identity-mismatched existing documents. Session ID, StartedAt, ProviderID and optional 32-hex ChatID are immutable for Save. Only explicit AssignChat may attach an unassigned existing part; it preserves all other fields, allows resolving ambiguous legacy submissions, and never reassigns a nonempty ChatID.
- Document field order is `version`, `summary`, `session`. List selects at most 200 newest file mtimes and reads only a bounded header, then sorts summaries by session start. Body corruption is detected by Load/Save; List deliberately cannot validate unread bodies. ForChat scans all headers without the 200-file cap and sorts parts chronologically. Explicit ChatID is authoritative; Association infers legacy ownership only when all submissions name one valid chat. Unassigned or ambiguous legacy parts remain unchanged and available through List; reads never migrate files.
- Limits: 10000 final segments, 32 MiB document, 65536 code points / 256 KiB per final text, 500 errors, 1000 submissions, 256 dictionary entries, 2 sources. Final events after EndedAt are valid; Sources may be empty until capture metadata arrives. Segment StartedAt is rounded to seconds by UI and can slightly precede session start. All persisted/exposed times normalize to UTC.
- Clone must copy every nested slice, including submission SegmentIDs. Stores for the same absolute directory share a mutex; I/O must remain outside controller/audio locks.
- Validate with `go test -race ./internal/audiohistory`; tests use temporary directories and no providers or audio hardware.
